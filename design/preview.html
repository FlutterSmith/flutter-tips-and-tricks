      Measure execution time with Stopwatch

      BeginnerDart language2 min read✓ Verified · Flutter 3.47.5 · 21 Sep 2026

      Need to know how long an async call takes? Wrap it in a small helper built on Stopwatch. It returns the result and the time it took.

      Why not DateTime.now()?

      DateTime.now() reads the wall clock. The wall clock can jump when the device syncs time or the user changes it, so the difference between two readings can be wrong, or even negative.

      Stopwatch uses a monotonic clock. It only moves forward, which is exactly what you want when timing code.

      What changed since the original. Upstream tip #116 timed code with DateTime.now().difference(). This version uses Stopwatch and returns a record, so callers get the value and the duration together.

      Pitfalls

      Timing a single run in debug mode tells you very little. Profile in --profile mode, run it a few times, and look at the spread.
